# The Chocolate Factory Line

A Grade 4 self-paced SKAI Space mission (coding and algorithms: a sequence is a chain of dependencies).
Meera's school-mela stall needs chocolates, but the steps on her factory line got mixed up. The child
orders the chocolate line, runs it, fixes one step at a time, states the rule, then orders a candle line
and a cupcake line on their own.

## How to launch

- **From disk:** double-click `index.html`. No installation, server or internet connection is needed.
- **On a website or LMS:** upload the whole folder as it is to any static web host and open `index.html`.

Keep the folder together: `index.html` needs `css/`, `js/`, `assets/` and `audio/` beside it.

The title screen shows a loading bar until every picture and sound is ready, then START MISSION appears
(a few seconds on a school connection, instant from disk).

## Offline

Everything the game uses is inside this folder, including the font. It makes no requests to other sites,
so it plays fully offline.

## Browsers

Chrome, Edge, Firefox and Safari on desktops, laptops and tablets. Sound uses Ogg Opus, which plays in
Chrome, Edge, Firefox, Android and Safari 18.4 or later. Older Safari (iPads that cannot update to
iPadOS 18.4) runs the whole game without sound.

Sound starts on the first tap. The speaker button at the top replays Meera's last line or mutes all sound.
